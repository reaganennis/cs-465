Architecture
Compare and contrast the types of frontend development you used in your full stack project, including Express HTML, JavaScript, and the single-page application (SPA).

Throughout this project, I worked with both a traditional web application and a single-page application (SPA). The Express HTML implementation relied on server-side rendering, where pages were generated by the server and reloaded whenever a user navigated between views. This approach was effective for displaying content but required additional page requests for each interaction.

In contrast, the Angular SPA provided a more dynamic user experience. Rather than reloading entire pages, the application updated specific components within the browser, creating a faster and more responsive interface. JavaScript served as the foundation for both approaches by handling application logic, user interactions, and communication between the frontend and backend. While Express HTML focused on delivering server-rendered content, the SPA emphasized client-side rendering and a seamless user experience.

Why did the backend use a NoSQL MongoDB database?

MongoDB was selected because it is a NoSQL database that stores information in flexible JSON-like documents. This structure works well with JavaScript-based full stack applications because data can be represented consistently across the frontend, backend, and database layers. MongoDB also allows developers to work with varying data structures without requiring rigid schemas, making it easier to scale the application and manage travel-related information efficiently.

Functionality
How is JSON different from JavaScript, and how does JSON tie together the frontend and backend development pieces?

JSON (JavaScript Object Notation) is a lightweight data-interchange format used to transmit and store data, while JavaScript is a programming language used to create application functionality. Although JSON uses a syntax similar to JavaScript objects, it exists solely as a data format and does not contain executable code.

JSON serves as the connection between the frontend and backend. When users request or modify information, the frontend sends data to the backend in JSON format through API requests. The backend processes the request, interacts with MongoDB, and returns JSON responses. This consistent data format allows all application layers to communicate effectively.

Provide instances in the full stack process when you refactored code to improve functionality and efficiencies, and name the benefits that come from reusable user interface (UI) components.

During development, I refactored portions of the application by organizing code into reusable Angular components and services. Instead of duplicating functionality across multiple pages, common features were consolidated into shared components, making the codebase easier to maintain and update. I also simplified API interactions through service classes that centralized backend communication.

Reusable UI components provide several benefits, including improved maintainability, reduced code duplication, greater consistency across the application, and faster development. When updates are required, changes can be made in a single component rather than throughout the entire application. This approach improves efficiency while reducing the likelihood of introducing errors.

Testing
Explain your understanding of methods, endpoints, and security in a full stack application.

Methods, endpoints, and security are essential elements of a full stack application. Endpoints are the URLs that provide access to application resources, while HTTP methods define the actions that can be performed on those resources. Common methods include GET for retrieving data, POST for creating data, PUT for updating data, and DELETE for removing data.

Testing these endpoints ensures that requests return the correct responses and that application functionality operates as intended. As security features were added to the application, testing became more complex because authentication and authorization processes had to be verified in addition to basic functionality. Security measures such as login authentication, token validation, and protected routes help ensure that only authorized users can access administrative functions and sensitive data. Understanding these concepts demonstrated the importance of balancing functionality with security in modern web applications.
